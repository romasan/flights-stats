# CLAUDE.md — Инструкции для Cline

Этот файл содержит правила, которым Cline должен следовать при внесении любых изменений в проект.

## Общие правила

1. **Проверяй документацию при изменениях.** Перед внесением любых изменений в код или конфигурацию проекта ознакомься с существующей документацией: `README.md`, `CHANGELOG.md` и данным файлом `CLAUDE.md`.

2. **Синхронизируй документацию с кодом.** Если внесённые изменения затрагивают:
   - структуру проекта (добавление/удаление/переименование файлов),
   - логику работы приложения,
   - способы запуска,
   - зависимости,
   - внешние API или URL,
   - любые другие функциональные изменения, —
   то **обнови `README.md`** соответствующим образом. Документация не должна противоречить фактическому состоянию кода.

3. **Обновляй `CHANGELOG.md`.** Каждое изменение, которое попадает под правила п. 2, должно быть отражено в `CHANGELOG.md`:
   - добавь новую запись в начало списка (под заголовком `## Changelog`);
   - формат: `## YYYY-MM-DD — одно предложение (не более 200 символов)`;
   - язык записей в `CHANGELOG.md` — **английский**;
   - если изменений несколько, каждое записывается отдельной строкой с новой датой.

4. **Проверяй корректность формата.** Убедись, что записи в `CHANGELOG.md` не превышают 200 символов и написаны на английском языке.

## Структура проекта

Проект состоит из:

- `fetch_flights.sh` — Bash-скрипт для загрузки данных о рейсах аэропорта Пулково (LED) с API в JSON-файлы.
- `flights-stats.html` — одностраничное веб-приложение для визуализации статистики рейсов (Chart.js, chartjs-plugin-datalabels, chartjs-chart-matrix).
- `README.md` — документация проекта (на русском языке).
- `CLAUDE.md` — данный файл с инструкциями для Cline.
- `CHANGELOG.md` — журнал изменений (на английском языке).

Подробное описание архитектуры и логики работы — в `README.md`.

## Процесс внесения изменений

При выполнении задачи:

1. Изучи все файлы в проекте и текущую документацию.
2. Внеси изменения в код.
3. Обнови `README.md`, если изменилась структура или логика проекта.
4. Добавь запись в `CHANGELOG.md` на английском языке (одна строка, не более 200 символов, с текущей датой в формате `YYYY-MM-DD`).
5. Проверь, что документация не противоречит коду.
